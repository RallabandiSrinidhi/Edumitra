# EDUMITHRA - AI-Powered Full-Stack Learning Platform 

EDUMITHRA is a full-stack educational web application providing personalized AI guidance, interactive career roadmaps, progress analytics, and dynamic learning metrics.

##  Project Architecture
- **Frontend**: Glassmorphism UI built with HTML5, CSS3 (Flexbox & CSS Grid), and Vanilla JavaScript (ES6).
- **Backend**: Python API endpoints with SQLite database integration for authentication and user data management.

## Key Features
- **User Authentication**: Login & registration endpoints and UI.
- **Interactive AI Tutor**: Chat interface providing simulated learning assistance.
- **Progress Tracking Dashboard**: Streak counters, quiz performance metrics, and interactive progress bars.
- **Career Roadmaps**: Smooth-scrolling track navigation for Web Dev, Python, and AI/Data Science.
- **Responsive Design**: Optimized for Desktop, Tablet, and Mobile devices.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Python, SQLite3, REST API Endpoints
- **Environment**: Virtual Environment (`venv`), Groq API

##  How to Run Locally

1. **Clone the Repository**:
   git clone https://github.com/RallabandiSrinidhi/Edumitra.git
   cd Edumitra

2. **Run Backend**:
   Navigate to edumithra-backend and run:
   python main.py

3. **Run Frontend**:
   Navigate to edumitra-frontend and open index.html in your browser.
